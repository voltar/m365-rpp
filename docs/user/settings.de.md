# Persönliche Einstellungen

Unter **Einstellungen** steuern Sie, was **für Sie** gilt – nicht die Regeln des ganzen Teams.

## Typische Bereiche

- **Profil** — Anzeige Ihrer Identität (aus Microsoft 365).
- **Genehmigung** — Standard-Genehmiger, falls das Team persönliche Wahl erlaubt.
- **Benachrichtigungen** — wie Sie über Antragsstände informiert werden.
- **Outlook-Kalender** — ob genehmigte Abwesenheiten synchronisiert werden (Team kann das vorgeben).
- **Regional** — Sprache und Zeitzone aus Microsoft 365; kein Sprachumschalter in RPP.

## Speichern

Änderungen speichern oder auf Standard zurücksetzen, je nach angezeigten Schaltflächen.

Teamweite Regeln (Mindestbesetzung, Abwesenheitstypen, Sync-Pflicht) liegen im **Team Admin Center** und sind nur für Team-Besitzer sichtbar.
