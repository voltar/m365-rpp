# Outlook-Synchronisation

Genehmigte Abwesenheiten können optional im **Outlook-Kalender** erscheinen.

## Persönlich

In **Einstellungen** unter **Outlook-Kalender**: Option für genehmigte Ferien/Abwesenheiten mit Outlook. Im Abwesenheitsformular gibt es oft zusätzlich **Mit Outlook synchronisieren**.

## Teamvorgabe

Das Team kann Outlook-Sync **optional**, **obligatorisch** oder **deaktiviert** vorgeben. Dann ist der persönliche Schalter ggf. gesperrt.

## Was Sie erwarten dürfen

- Nach Genehmigung kann ein Termineintrag entstehen oder aktualisiert werden.
- Ablehnung oder Löschung kann den Eintrag entfernen oder anpassen.
- Statushinweise in RPP, wenn die Synchronisation läuft oder fehlschlägt.

RPP ersetzt nicht den gesamten Outlook-Kalender – nur die von RPP verwalteten Abwesenheiten im Rahmen der Konfiguration.
