# Personal settings

Under **Settings** you control what applies **to you** — not whole-team rules.

## Typical sections

- **Profile** — your identity (from Microsoft 365).
- **Approval** — default approver if the team allows a personal choice.
- **Notifications** — how you learn about request status changes.
- **Outlook calendar** — whether approved absences sync (the team may mandate this).
- **Regional** — language and time zone from Microsoft 365; no language switcher in RPP.

## Saving

Save changes or reset to defaults using the buttons shown.

Team-wide rules (required staffing, absence types, sync policy) live in the **Team Admin Center** and are visible to team owners only.
