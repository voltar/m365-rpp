# Product Vision

M365 Ressourcen & Präsenzplanung is a Microsoft Teams app for IT resource, presence, and operational capacity planning.

The product is not a vacation calendar, SharePoint list, Planner clone, or Microsoft Project replacement. It is an operations planning platform for teams that need visibility across people, skills, capacity, absences, maintenance windows, and organization boundaries.

## Target Users

- IT Platform Services
- Infrastructure and cloud teams
- Security teams
- Service management
- Operations managers

## Core Principles

- Feel like a native Microsoft Teams application.
- Support Organisation-A and Organisation-B collaboration.
- Model employees with multiple teams, skills, and roles.
- Keep UI text localized from Sprint 1, 
- Translation into many languages in later Phases
- Keep backend access behind services when SharePoint Lists are introduced.
