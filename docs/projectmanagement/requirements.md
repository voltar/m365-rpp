# Requirements

## Sprint 1

- Build a polished clickable Teams-style UI prototype.
- Show a horizontal three-month timeline/Gantt view.
- Render one row per employee.
- Show vacation entitlement, booked days, and remaining balance.
- Support multiple team and skill memberships per employee.
- Group the view by teams or skills.
- Display Organisation-A and Organisation-B badges.
- Show SG and Dübendorf school holidays as background bands.
- Highlight critical understaffing and capacity risks.
- Provide an "absence request" side panel.
- Support German and English from the start.
- Avoid hard-coded UI text in components.
- Keep mock data typed and realistic.

## Later Sprints

- Replace mock data with SharePoint Online Lists through service classes.
- Add approval flows, Graph presence, Outlook synchronization, and reporting.
