## 11. DESIGN PRINCIPLES

People first – die Informationen müssen auf einen Blick erfassbar sein.
One screen, one decision – jede Ansicht unterstützt eine konkrete Entscheidung.
Visual before textual – Zeitbalken, Farben und Heatmaps statt langer Listen.
Configuration over customization – möglichst alles konfigurierbar statt fest im Code.
Enterprise quality – kein Prototypen-Charakter.
